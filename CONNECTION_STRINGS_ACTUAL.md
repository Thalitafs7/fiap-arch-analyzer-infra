## 15. Notes

- `<random>` = AWS-generated suffix (e.g., `abcd1234`)
- `<auto-generated>` = 24-char password gerado por `random_password` resource
- Passwords com special chars: `!#$%*-_+=` (sem `/`, `@`, `'`, `"`, `;`)
- RDS endpoints só são acessíveis de dentro da VPC (private subnets)
- SQS URLs são públicas mas requerem AWS credentials (IAM)
- ECR requer `aws ecr get-login-password` antes de `docker push/pull`
- MongoDB/Redis rodam em StatefulSets no namespace `data`
